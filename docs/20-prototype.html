怎么用（评审指引）

  • 1. 直接用浏览器打开本文件（无需服务器）；不带参数时展示全部 4 个页面的 default 状态。
  • 2. 页面间跳转：使用下方导航条或页面内链接（链接为可点击的真实 a 元素，整页刷新）。
  • 3. 边界状态直达：按下一节索引表的「直达 URL」打开，形如 ?page=draw&state=noquota#page-draw--noquota；追加 page 参数可只展示单页。
  • 4. 状态切换完全由 CSS 承担：data-state 控制显隐、data-page 控制页面筛选；未知取值自动回退 default / all。
  • 5. 抽奖页 ?state=win 会看到转盘落到 ③ 号扇区并高亮、指针停在落点（模拟动画停稳后的静止帧）；?state=drawing 可看到转盘旋转动效（关闭系统「减少动态效果」后更明显）。
  • 6. 本原型不含真实抽奖判定、接口、路由守卫、无刷新路由过渡；也不提供「点击切换状态」——状态唯一来源是 URL 查询参数（见文件顶部 [4] 动效边界）。

索引表：页面 x 状态（下游 engineer / test-designer / test-executor 按锚点定位）

直达 URL 均相对本文件，完整形式为 docs/20-prototype.html?page=<页面>&state=<状态>#<锚点>。 锚点 = 该状态下发生变化的区块（原型刻意只保留一份表单 / 页面 markup，用状态叠加呈现，避免多份重复结构漂移）： 整块替换类状态（loading / error / empty）锚点指向替换后的整块；叠加类状态（invalid / loginfail / guard / noquota / drawing / drawfail / win / lose）锚点指向被叠加或以叠加方式出现的元素。 注册页与登录页的表单常驻显示（不随状态隐藏），仅错误 / 提交中 / 提示区块随状态出现。 全部文案见文末「文案清单（可替换）」。

原型区块 → shadcn-vue 组件映射表（供 engineer 照抄）

本原型是零依赖单文件 HTML，没有运行 Tailwind / shadcn-vue：下表说明「原型里看到的这个区块，在 src/ 里应该由哪个 shadcn-vue 组件 + 哪组变体实现」。组件一律用 npx shadcn-vue@2.x add <组件名> 添加（固定主版本，禁止 @latest、禁止手写复制源码）； src/components/ui/ 只读，业务定制走外层包裹 / props / 插槽 / Tailwind 类名覆盖。

可访问性（a11y）与豁免说明

已在原型中覆盖

  • 对比度（均为本文件实际取值的计算值，WCAG 2.x 相对亮度公式）： 正文 --foreground #0a0a0a / --card 白 ≈ 19.8:1（≥16:1）； 正文 / --background ≈ 18.1:1； 次要文本 --muted-foreground 0.439 / 白 ≈ 7.8:1（AA 正文 4.5:1 上限余量充足）、/ --muted ≈ 7.2:1； 错误文本 --destructive 0.46 0.176 27.5 / 白 ≈ 7.8:1，白字置于 destructive 实底 ≈ 7.8:1（双向均 ≥7:1，故红底白字按钮在小字号下也达 AA）； --primary-foreground / --primary ≈ 17.2:1。 三个刻意加深的令牌（muted-foreground 默认 4.7:1、destructive 默认 4.8:1、ring 默认 2.6:1）在文件顶部注释 [2] 有记录。
  • 焦点可见：统一 :focus-visible 焦点环（--ring 0.556 / 白 ≈ 4.7:1，满足 WCAG 2.4.11 非文本对比 3:1）；按钮 / 输入框额外叠加 3px 环形阴影。
  • 语义化结构：nav / section / table / caption / th[scope] / label[for]；标题层级 h1-h4 连续。
  • 表单：每个输入绑定 label[for]，规则说明与错误用 aria-describedby 关联；错误文本 role="alert"，提交中提示 role="status"。
  • 弹层：role="dialog" aria-modal="true" aria-labelledby（标题 id 指向 DialogTitle 等价物）。
  • 键盘可达：全部交互元素为原生 a / button / input（Tab 可达、Enter/Space 激活）。
  • 装饰性图形（转盘 SVG、指针、空态插画、Alert 图标、spinner）统一 aria-hidden="true" focusable="false"，语义由相邻文本 / 图例承载，不依赖图形阅读。
  • 错误态不只用颜色表达：destructive 边框同时配 FormMessage 文本 + 图标；Badge 内均有文字。
  • 保留 skip link（跳到「页面 x 状态」索引表），首个 Tab 即可见。

豁免项（静态原型，原因与补齐方）

  • 焦点陷阱 / 焦点回收：静态原型无真实弹层生命周期 → 由 shadcn-vue Dialog（reka-ui）自带，engineer 无需自实现。
  • 屏幕阅读器实时播报（live region）：状态由 CSS 切换、无真实事件流 → 实现时抽奖结果由 Dialog 获得焦点后播报，次数变化用 aria-live="polite"。
  • 真实 disabled 属性：CSS 无法切换 disabled，原型禁用态仅为样式 → 实现必须使用真实 disabled（规范红线：前端禁用只是体验，鉴权与限量以服务端为准）。
  • 移动端抽屉 / 断点下的表格卡片化：原型在 375-428px 用横向滚动保证可读（PRD 4.4）；若产品要求卡片化，由 engineer 结合组件规范决定。
  • 暗色模式（.dark）令牌：本次不做原型；engineer 从 shadcn 主题块引入并重跑对比度检查。
  • 颜色对比度自动化检测：本文件为静态原型，不接 axe / Pa11y；上述比率为人工按 WCAG 公式计算，E2E 阶段可加 @axe-core/playwright 复核。

原型注解 / 实现提示（不进入实现，仅供 engineer 参考）

  • 结果只能来自后端：请求不携带任何影响结果的业务参数（幂等键除外）；前端只负责按返回的条目标识定位扇区、播动画（FR-05-R1 / FR-06）。
  • 动画口径：原型用纯 CSS（@keyframes 转 3 圈 + 落点 transition）示意「≥2 圈后减速停稳」；实现时按返回条目标识计算目标角度（360 * n + 目标角度），最终落点必须等于后端返回条目。关闭「减少动态效果」时原型仍会直接呈现静止落点。
  • 顺序：点击后按钮立即禁用 → 等待响应 → 成功才播动画 → 动画结束展示 Dialog；失败不播动画并复位（FR-05 交互细节 / FR-06-2）。
  • 幂等：每次新抽奖生成新的 Idempotency-Key（UUID）；失败重试沿用同一 key（FR-08-4）。
  • 次数：判定以服务端为准（UTC+8 自然日，不信任客户端时间）；每次进入页面与每次抽奖后与服务端同步剩余次数（FR-04 / FR-07-2）。
  • 按钮禁用仅为体验：服务端仍逐次校验；前端隐藏 / 禁用不构成鉴权与限额（规范红线）。原型受 CSS 限制只能用样式表达禁用，实现必须用真实 disabled。
  • 可测试性：测试环境可用确定性随机源 / 权重覆盖以稳定验证中奖与未中奖两条链路（FR-05-R9），生产不可达。
  • 图例与转盘的一致性：图例为有序列表、转盘为装饰性 SVG（aria-hidden），屏幕阅读器只读图例；扇区短名（一等奖 / 二等奖 …）与图例全名一一对应，扇区颜色同时由图例色块承载，不依赖颜色单独区分。
  • 未覆盖：中奖彩带 / 音效（PRD Could-C1）不做。

与接口的交互点（占位说明，最终以 docs/30-architecture.md 为准）

本原型不预设接口路径与模块编号（属 software-architect 职责），仅标注前端需要的交互点，供 engineer 对齐：

  • 1. 拉取奖池（页面进入时）—— 响应需含条目标识（供扇区定位）+ 名称 + 类型 + 启用状态；不含权重与库存（FR-03-1）。
  • 2. 提交抽奖（点击抽奖时）—— 请求不携带影响结果的业务参数；请求头带 Idempotency-Key（UUID，重试沿用同一值）；响应返回结果条目标识 + 最新剩余次数（FR-05-R10）。
  • 3. 我的中奖记录（记录页）—— 分页参数 pageIndex（从 1 起）/ pageSize（默认 10）；不接受 userId 参数（FR-09-1）。
  • 4. 通用：受保护接口未登录返回 401（前端引导登录并回跳）；统一响应 ApiResult<T>，code=0 成功、>=1000 为业务异常且前端直出后端文案（错误码由 engineer 按 docs/error-codes.md 取号登记，PRD 不预设号码）。
